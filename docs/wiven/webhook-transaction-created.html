Webhooks

Pagamentos

Os webhooks são usados para notificar o seu sistema sobre eventos relacionados a criação de transações e monitoramento dos pagamentos.

Webhook de Transação

Quando um evento ocorre, a notificação é enviada para a URL configurada com o seguinte formato:

TRANSACTION_CREATED

event
enum
Sempre retornado

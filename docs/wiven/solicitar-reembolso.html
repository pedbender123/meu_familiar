Solicitar reembolso

Esta rota e utilizada para solicitar reembolso de uma transacao propria do produtor autenticado.

Essa rota requer autenticação
POST
/gateway/producer/refunds

Authorization

x-public-key
string
Obrigatório

Chave publica da API do produtor.

x-secret-key
string
Obrigatório

Chave secreta da API do produtor.

Body

application/json
transactionId
string
Obrigatório

ID da transacao que sera reembolsada. A transacao deve pertencer ao produtor autenticado.

reason
string
Obrigatório

Motivo da solicitacao de reembolso.

description
string
null

Descricao opcional com detalhes adicionais.

Retorno

200 OK

string
Sempre retornado

ID da solicitacao de reembolso criada.

Sempre retornado

ID da transacao vinculada ao reembolso.

producerId

Sempre retornado

ID do produtor dono da transacao.

Sempre retornado

Status atual da solicitacao de reembolso.

COMPLETED
CANCELED
